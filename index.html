Git & GitHub Master Guide

Learn Git and GitHub from beginner to advanced with practical commands and workflows.

Start Learning GitHub Workflow

01 — FOUNDATION

Git Basics

git --version

Check the installed Git version.

git --version

git config

Configure your Git username.

git config --global user.name "Your Name"

git config email

Configure your Git email.

git config --global user.email "you@example.com"

git config --list

Display Git configuration.

git config --list

git init

Create a new Git repository.

git init

git status

Check the current repository status.

git status

02 — VERSION CONTROL

Staging & Commits

git add

Add a file to the staging area.

git add index.html

git add .

Stage all changed files.

git add .

git commit

Save staged changes.

git commit -m "Initial commit"

git log

View commit history.

git log

git log --oneline

Display compact commit history.

git log --oneline

git diff

See changes that are not staged.

git diff

03 — BRANCHING

Branches & Merging

git branch

List existing branches.

git branch

Create Branch

Create a new branch.

git branch feature

git switch

Switch to another branch.

git switch feature

Create + Switch

Create and switch to a branch.

git switch -c feature

git merge

Merge another branch.

git merge feature

Delete Branch

Delete a local branch.

git branch -d feature

04 — REMOTE DEVELOPMENT

GitHub Commands

git remote

View remote repositories.

git remote -v

git remote add

Connect local Git to GitHub.

git remote add origin https://github.com/user/repo.git

git push

Upload commits to GitHub.

git push origin main

git push -u

Push and set the upstream branch.

git push -u origin main

git clone

Download a GitHub repository.

git clone https://github.com/user/repo.git

git pull

Download and integrate remote changes.

git pull origin main

git fetch

Download remote changes without merging.

git fetch origin

05 — RECOVERY

Undo & Restore

git restore

Restore a working file.

git restore index.html

git restore --staged

Remove a file from staging.

git restore --staged index.html

git reset

Move HEAD and modify staging.

git reset HEAD~1

git revert

Create a new commit that reverses an old commit.

git revert HEAD

06 — TEMPORARY STORAGE

Git Stash

git stash

Temporarily save uncommitted changes.

git stash

git stash list

View saved stashes.

git stash list

git stash pop

Apply the latest stash and remove it.

git stash pop

git stash apply

Apply a stash without deleting it.

git stash apply

07 — ADVANCED

Advanced Git

git tag

Create a release tag.

git tag v1.0.0

Push Tag

Push a tag to GitHub.

git push origin v1.0.0

git reflog

View reference history.

git reflog

git cherry-pick

Apply a specific commit to your branch.

git cherry-pick abc123

git rebase

Reapply commits on top of another base.

git rebase main

git blame

See who changed each line.

git blame index.html

08 — DAILY WORKFLOW

Professional Git Workflow


# 1. Clone project

git clone https://github.com/user/project.git

# 2. Enter project

cd project

# 3. Create feature branch

git switch -c feature

# 4. Work on your project

# 5. Check changes

git status

# 6. Stage files

git add .

# 7. Commit

git commit -m "Add new feature"

# 8. Push branch

git push -u origin feature

# 9. Create Pull Request on GitHub

# 10. After merging, update main

git switch main

git pull origin main
